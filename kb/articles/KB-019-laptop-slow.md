## Symptoms
- Apps take a long time to open; the laptop freezes or the fan runs constantly.

## Quick checks
1. Run `check_device_status`. Low disk space is a common cause (KB-017).
2. Ask when the laptop was last restarted. Many users only close the lid for weeks.
3. Ask whether it started after an update or a new app install (KB-028).

## Fix
1. Restart the laptop (a full restart, not shutting the lid).
2. Open Task Manager and check which app uses the most CPU or memory; close it if it is not needed.
3. Install pending Windows updates and restart again.
4. Reduce browser tabs and startup apps (Task Manager, Startup tab).

## Escalate when
- Still slow after restart, updates, and cleanup: possible hardware fault or the laptop is due for replacement.
- Blue screens or repeated crashes.
