category: software

## Symptoms
- User needs an app that is not on their laptop.
- Install fails with "You need administrator permission".

## Quick checks
1. Check the Company Portal (Software Center) first. Approved apps can be installed there without IT.
2. Run `lookup_user` to note department and title for the approval.

## Fix
1. If the app is in the Company Portal, guide the user to install it there.
2. Otherwise, the request needs manager approval and a security review of the app.
3. Never share admin credentials or give the user local admin rights to install it themselves.
4. Do not install software from a link the user received by email.

## Escalate when
- The app is not in the Company Portal and the manager has approved it: escalate with the app name, version, business reason, and approver.
